#  AstroShop AI Lab — Observabilidad y Autoremediación con IA + Dynatrace

Laboratorio práctico donde aprenderás a usar un agente de IA integrado con Dynatrace para analizar, diagnosticar y resolver problemas de observabilidad sobre una aplicación real: **AstroShop**, una tienda de e-commerce basada en microservicios.

Cada participante trabaja sobre su propio namespace aislado en Kubernetes, con una instancia completa de AstroShop reportando telemetría a Dynatrace.

## ¿Qué vas a aprender?

El lab está dividido en tres partes acumulativas:

**Lab 1 — Análisis con DQL.** Enseñas al agente a consultar y analizar datos de Dynatrace usando DQL (Dynatrace Query Language), a través de instruction files que guían un análisis progresivo del estado de los servicios.

**Lab 2 — Autoremediación.** El flujo completo: el agente investiga un problema, propone la solución mediante un Pull Request, y tras la aprobación, la corrección se aplica automáticamente al cluster resolviendo el incidente. El agente construye artefactos de observabilidad reutilizables: notebooks, SLOs y dashboards, usando la herramienta correcta para cada tarea.

## Requisitos

Abre el repositorio en Codespaces (**Code → Codespaces → Create codespace**) y sigue la guía en `GUIA-PARTICIPANTE.md`.
